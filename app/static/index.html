    Model names

    • Full IDs carry the provider prefix, like google/gemini-3.5-flash.
    • The bare name works too: gpt-5.5 resolves to openai/gpt-5.5.
    • Claude model names such as claude-sonnet-4-5 are routed to the gateway's default model, and names containing haiku go to the small model. Claude models themselves are not available here.
    • The list refreshes every 6 hours. Each model gets a live chat request, a tool-call request and an image test (it must name the colour of a red and a blue image), and only working models are listed.

    What works

    • Yes Streaming on all three APIs.
    • Yes Tool calls, including multi-step agent loops and parallel calls.
    • Yes Images in user messages, on models marked vision. Send them as image_url parts (OpenAI) or image blocks (Anthropic), as a URL or base64 data URI.
    • No Claude Code's server-side tools, such as built-in web search. Local tools (Bash, Read, Edit, Write, Grep, MCP) work.
    • No Images returned by a tool. The model sees a placeholder instead.
    • No Visible thinking blocks in Claude Code. Reasoning models still reason, the text is just not shown.

    Troubleshooting

    SymptomFix
    401 invalid API keyCheck the key and that the header is Authorization: Bearer …. For Claude Code, use ANTHROPIC_AUTH_TOKEN and leave ANTHROPIC_API_KEY unset.
    404 model definitionThe model ID is wrong or was retired. Copy an ID from the list on this page.
    Claude Code: "Invalid model ID or insufficient subscription"Another Claude login or ANTHROPIC_* variable is overriding the settings. Run env | grep ANTHROPIC, unset the extras, and restart Claude Code.
    Codex hangs with no output in scriptscodex exec waits on stdin. Add </dev/null when running it from a script.
    Model ignores the screenshot or describes the wrong imageThe model has no vision support. Pick one marked vision.
    Agent replies but never edits filesThe model may not call tools reliably. Switch to a model marked tools.
